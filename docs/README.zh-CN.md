# Papertrail：本地论文研究助手

这是用于科研阅读的 RAG 应用，核心是“读论文、找相关工作、比方法、设计下一步实验”。默认使用本地 Qwen，不需要付费 API。

## 使用方法

1. 按主 README 安装并运行 `papertrail`。
2. 浏览器打开 `http://127.0.0.1:8765`。
3. 导入可提取文字的 PDF，或点击样例库体验。样例是明确标注的教学笔记，不冒充真实论文。
4. 左侧勾选论文，选择总结、方法对比或实验设计。
5. 点击正文中的 `[E1]` 等引用，查看对应原文和页码。
6. 使用 `Export .md` 导出报告和证据清单。

查找相关工作时，输入英文关键词较可靠，例如 `low rank adaptation`。点击 `Add abstract` 导入的是摘要；完整方法和实验分析需要上传完整 PDF。选择 Chinese 可以让模型尝试中文输出，但关键词检索不会自动把中文翻译成英文。

## 能在面试中讲的内容

- 为什么先建立 BM25 可测基线，而不是没有评估就堆叠向量数据库。
- 如何保存文档、页码、片段 ID，使生成答案可以追溯。
- 为什么“引用编号存在”不等于“引用能支持结论”。
- 小模型漏引文时如何只修正一次，并把失败如实展示。
- 为什么多篇对比需要为每篇论文保留证据位置。
- 如何限制队列、复用模型、缓存结果，让 8GB 笔记本也能运行。
- 如何区分真实网络检索、合成测试数据、实测生成和未验证能力。

## 已知限制

1.7B 模型能力有限，可能漏掉某个比较维度或生成不严谨的研究想法。请把原文放在旁边核对，实验建议是待验证的假设。扫描版 PDF、复杂表格和数学公式解析尚未实现。这个版本是本机单用户工具，不适合直接公开为多人在线服务。
